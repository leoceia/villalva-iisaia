## 1 — Prompt inicial

```
En html single page. HTML + Js + Css.
Desarrollar un login con usuario y contraseña. Validar que el usuario sea un mail y que la constraseña tenga al menos:
1 mayúscula
1 minúscula
1 número
para que aparezca el bótón de login,
el usuario debe elegir la mayor de tres cartas dadas vuelta. Esto debe hacerlo tres veces. Cada vez los valores de las cartas deben cambiar al azar.
si lo logra, aparece un botón de Login.
Luego del botón de login debe aparecer un cartel "bienvenido"```

**Qué devolvió:** Devolvió un login bastante bien logrado.

**Qué hice con eso:** quise experimentar hacer cambios de acuerdo a cómo yo me lo había imaginado.
